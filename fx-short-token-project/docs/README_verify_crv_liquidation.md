# CRV/USDC 爆仓验证工具使用说明

## 工具简介

`verify_crv_liquidation_binance.py` 是一个专门用于验证Binance USDC-M永续合约市场中CRV/USDC交易对爆仓记录真实性的工具。该工具通过Binance API查询用户交易历史，检测是否存在符合爆仓特征的交易记录。

## 功能特点

- 自动查询指定时间范围内的CRV/USDC交易历史
- 检测负实现盈亏的大额交易（爆仓核心特征）
- 提供详细的交易信息和盈亏统计
- 生成结构化的验证结果，用于保险理赔或审计

## 安装依赖

该脚本需要以下Python库：

```bash
pip install requests
```

## 配置说明

在运行脚本前，需要配置以下参数：

1. **API密钥配置**（推荐使用环境变量）：
   - `BINANCE_API_KEY`：从 Binance API 管理页面获取
   - `BINANCE_API_SECRET`：从 Binance API 管理页面获取（请妥善保管，勿分享）

2. **交易参数配置**：
   - `SYMBOL`：交易对，默认为'CRVUSDC'
   - `MIN_VALUE_USD`：最小开仓价值阈值，默认为100 USDC

3. **时间范围配置**：
   - 默认为过去24小时：`START_TIME = END_TIME - (24 * 60 * 60 * 1000)`
   - 也可以指定具体的开仓时间：`START_TIME = 1728275566000`（示例时间戳）

## 使用方法

1. 设置环境变量：

```bash
export BINANCE_API_KEY="your_key"
export BINANCE_API_SECRET="your_secret"
```

2. 运行脚本：

```bash
python verify_crv_liquidation_binance.py
```

## 验证逻辑

脚本通过以下步骤检测爆仓：

1. 调用Binance API查询指定时间范围内的CRV/USDC交易历史
2. 分析每笔交易的实现盈亏（realizedPnl）
3. 筛选出负实现盈亏且交易价值大于等于阈值的交易
4. 输出检测到的爆仓记录和汇总信息

## 结果解读

脚本运行后会输出以下信息：

- 查询到的交易记录数量和时间范围
- 每笔潜在爆仓的详细信息（交易ID、时间、数量、价格、价值、盈亏等）
- 累计实现盈亏统计
- 最终验证结果（爆仓真实或无爆仓/可能虚假）

## 常见问题与解决方案

1. **API错误 403/2010**：
   - 问题：IP限制导致的访问被拒绝
   - 解决：在Binance API管理页面添加当前IP到白名单

2. **API错误 -2015**：
   - 问题：无效的API密钥或签名
   - 解决：检查并确保API_KEY和API_SECRET正确无误

3. **无交易记录返回**：
   - 问题：时间范围设置不当或该时间内无交易
   - 解决：调整START_TIME和END_TIME参数，扩大查询时间范围

## 注意事项

- 请妥善保管您的API密钥和Secret Key，不要分享给他人
- 建议使用仅具有"读取"权限的API密钥，提高安全性
- 脚本默认只检测过去24小时内的交易，如需查询更长时间，请调整时间范围参数
- 爆仓检测基于负实现盈亏和交易价值阈值，实际应用中可能需要根据具体情况调整验证逻辑
