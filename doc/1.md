### 本地环境搭建指南：使用 Hardhat 开发 Solidity 合约

基于 f(x) 协议 v1 的代码（如之前提供的 FxVaultV1.sol），你可以在本地搭建一个完整的 Ethereum 开发环境，用于编译、测试和部署合约。推荐使用 Hardhat，它是专业的 Solidity 开发工具，支持本地节点模拟（Hardhat Network）。以下是 2025 年最新的步骤（基于 Node.js v22+），整个过程只需 10-15 分钟。确保你的系统是 Windows、macOS 或 Linux。

#### 1. **前提安装**
   - **Node.js**：下载并安装 Node.js v22 或更高版本（LTS 推荐）。访问 [nodejs.org](https://nodejs.org/) 下载安装包，安装后运行 `node -v` 验证（应显示 v22.x.x 或更高）。  
     这包括 npm 包管理器。
   - **Git**（可选，但推荐）：用于克隆仓库，如 `git clone https://github.com/AladdinDAO/fx-protocol-contracts`。

#### 2. **创建项目文件夹**
   - 在终端（Command Prompt、Terminal 或 VS Code 集成终端）中，创建一个新文件夹：
     ```
     mkdir fx-local-dev
     cd fx-local-dev
     ```
   - 初始化 npm 项目：
     ```
     npm init -y
     ```
     这会生成 `package.json` 文件。

#### 3. **安装 Hardhat 和依赖**
   - 安装 Hardhat：
     ```
     npm install --save-dev hardhat
     ```
   - 初始化 Hardhat 项目：
     ```
     npx hardhat init
     ```
     - 选择 “Create a JavaScript project” 或 “Create a TypeScript project”（推荐 TypeScript）。
     - 安装额外依赖：Hardhat 会提示安装 `@nomicfoundation/hardhat-toolbox`（包含编译、测试、部署工具）。
       ```
       npm install --save-dev @nomicfoundation/hardhat-toolbox
       ```
   - 对于 f(x) 代码，安装 OpenZeppelin（用于 IERC20 等）：
     ```
     npm install @openzeppelin/contracts
     ```
   - 如果用 Chainlink oracle（如 WBTC 价格源），安装：
     ```
     npm install @chainlink/contracts
     ```

#### 4. **项目结构设置**
   Hardhat 会自动生成以下结构：
   ```
   fx-local-dev/
   ├── contracts/     # 放置 Solidity 合约 (e.g., FxVaultV1.sol)
   ├── scripts/       # 部署脚本 (e.g., deploy.js)
   ├── test/          # 测试文件 (e.g., vault.test.js)
   ├── hardhat.config.js  # 配置 (网络、编译器)
   └── package.json
   ```
   - **复制 f(x) 代码**：将之前提供的 `FxVaultV1.sol`、`FToken.sol`、`XToken.sol` 放入 `contracts/` 文件夹。
   - **配置 hardhat.config.js**（示例，针对本地 + 测试网）：
     ```javascript
     require("@nomicfoundation/hardhat-toolbox");
     
     module.exports = {
       solidity: "0.8.24",  // Solidity 版本
       networks: {
         hardhat: {  // 本地网络
           chainId: 31337,
         },
         sepolia: {  // 测试网 (需私钥)
           url: "https://sepolia.infura.io/v3/YOUR_INFURA_KEY",
           accounts: ["YOUR_PRIVATE_KEY"],
         },
       },
     };
     ```

#### 5. **启动本地网络并测试**
   - **启动本地节点**（模拟 Ethereum 主网）：
     ```
     npx hardhat node
     ```
     - 这会运行一个 JSON-RPC 服务器（默认 http://127.0.0.1:8545），并生成 20 个测试账户（带 ETH）。
   - **编译合约**：
     ```
     npx hardhat compile
     ```
     - 输出在 `artifacts/` 文件夹。
   - **运行测试**：创建 `test/vault.test.js`（示例测试 mint 函数）：
     ```javascript
     const { expect } = require("chai");
     const { ethers } = require("hardhat");
     
     describe("FxVaultV1", function () {
       it("Should mint f and x tokens", async function () {
         const [owner] = await ethers.getSigners();
         // 部署合约...
         // expect(await vault.mint(...)).to.emit...
       });
     });
     ```
     运行：
     ```
     npx hardhat test
     ```
   - **部署到本地**：创建 `scripts/deploy.js`：
     ```javascript
     async function main() {
       const FxVault = await ethers.getContractFactory("FxVaultV1");
       const vault = await FxVault.deploy(/* 参数 */);
       console.log("Vault deployed to:", await vault.getAddress());
     }
     main();
     ```
     运行（在另一个终端）：
     ```
     npx hardhat run scripts/deploy.js --network hardhat
     ```

#### 6. **推荐工具与 IDE**
   - **VS Code**：安装 Solidity 扩展（Juan Blanco's Solidity），用于语法高亮和调试。
   - **Tenderly** 或 **Remix IDE**：可选，用于可视化调试。
   - **Infura/Alchemy**：免费 RPC 用于测试网部署（注册获取 API Key）。

#### 7. **常见问题排查**
   - **Node 版本低**：升级到 v22+。
   - **端口冲突**：`npx hardhat node --port 8546`。
   - **Gas 错误**：本地网络无限 Gas，无需担心。
   - **扩展到其他代币**：如 WBTC，mock collateral 地址在测试中（用 ethers 部署假 ERC20）。

搭建完成后，你可以 fork f(x) 代码，模拟 WBTC 等代币的 mint/rebalance。更多细节参考 Hardhat 官方文档。 如果遇到具体错误，提供日志我可帮忙调试！
